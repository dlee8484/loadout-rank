Model2026-10-20

Voxtral 3 speech models + voice agent API

Mistral

A new family of speech models plus a voice agent API that chains realtime transcription, a Mistral LLM for reasoning and tool calls, and speech output in one streaming pipeline; it can answer and place calls over SIP and run in browsers and apps over WebRTC. Voxtral Small Transcribe 3 handles 50+ languages with diarization and context biasing ($0.004/min); Voxtral Mini Transcribe 3 is 4B parameters ($0.0035/min batch); Mini Transcribe Realtime 3 targets sub-500ms latency ($0.008/min); Voxtral Mini TTS 3 covers 35+ languages and 50+ dialects with emotion and pacing control ($13 per 1M characters). Voice agent API from $0.04/min with Mistral Small 4. Via Mistral's API or self-deployment; comparisons are Mistral's own.

Model2026-10-20

Ornith-1.5-122B (open weights, MIT)

Ornith

A 122B mixture-of-experts reasoning model for coding and agent work that Ornith says serves on a single 80GB GPU; 262,144-token context, extendable to about 1M with YaRN. Lab-reported scores: SWE-bench Verified 84.5, Terminal-Bench 2.1 81.2, SWE-bench Pro 76.9. MIT-licensed weights on Hugging Face in BF16 plus FP8, NVFP4, GGUF and MLX builds, and on Ollama (ollama run ornith-1.5:122b). Ornith-1.5 extends Ornith-1.0, which was built on Qwen3.5 and Gemma 4. Benchmarks are Ornith's own.

Creative2026-10-20

Fibo 2.0 (open weights, image generation + editing)

Bria

Bria's 8B-parameter model puts text-to-image and instruction-based image editing in one set of weights, with masked edits and up to 4 reference images, structured JSON (VGL) prompts and better text rendering. Two checkpoints: Fibo 2.0 Dev (full base for fine-tuning) and Edit Turbo (4-step editing). Bria cites #1 among open-weights models for image editing on Artificial Analysis as of Oct 20. Trained only on licensed data; weights are CC BY-NC 4.0 (commercial use needs a Bria agreement); also on the Bria API, fal and ComfyUI nodes.

Creative2026-10-20

FastH3 Omni (open-weight fast video + audio)

Hao AI Lab

FastVideo (Hao AI Lab, UC San Diego) with Nuva Lab open-sourced a distilled MiniMax H3 model for reference-guided video with synchronized stereo audio: a prompt plus up to 9 images, 3 videos and 3 audio clips (12 references max) produces 5–15 second clips at 24 fps in eight transformer evaluations. FastVideo measured up to ~12× lower end-to-end latency than the base model on eight GB200 GPUs; NVFP4 weights and recipes target DGX Spark and RTX 5090, with a ComfyUI FP8 build. Weights use the MiniMax H3 community license.

Tiny streaming TTS models that run offline on phones, laptops, a Raspberry Pi 5 and inside a browser tab: Phonon 31m (English, 64.5 MB, Apache 2.0) and Phonon 40m in English, French, German, Spanish and Portuguese plus a multilingual model (CC BY-NC 4.0, gated). Rust runtime with Python, npm, Swift and Android bindings and an OpenAI-compatible speech server; Gradium says up to 22× faster than real time on an iPhone 16 Pro. Stable runtime v0.4.0 published Oct 20; Gradium's announcement post is dated Oct 21.

Model2026-10-19

Clairic extraction model on Workers AI (preview)

Cloudflare

Cloudflare's first System One extraction model (@cf/cloudflare/clairic): send text, plus up to four images, with a schema of typed fields and get one typed value per field (exact text spans with character offsets, numbers, dates, durations, lists, estimates with an 80% interval, and forecasts up to 64 steps), or null when the input doesn't determine it. Every answer carries a confidence score and p_null. Answers in one pass without generating tokens and charges only for input: $0.10 per 1M input tokens; 65,536-token context. Preview on Workers AI; Cloudflare says open weights are coming soon.

Model2026-10-19

Mercury 3 (diffusion LLM)

Inception

Inception's largest diffusion language model, generating tokens in parallel rather than one at a time: Inception reports 1,068 tokens/s on NVIDIA GPUs and says it matches or beats GPT-6 Luna and Claude Haiku 5.5 on its benchmarks while running 4–8× faster. 1M-token context (up from 260K on Mercury 2.5). List price $0.20 / $0.70 per 1M input/output tokens, 50% off at launch ($0.10 / $0.35); cached input 90% off. OpenAI-compatible; on the Inception API, OpenRouter, Baseten and Vercel, with 100M free tokens for new API keys. Benchmarks are Inception's own.

Creative2026-10-19

JST-2 (physics-native world model)

Viggle

Viggle's world foundation model represents scenes as persistent 3D "atoms" instead of pixels. Viggle says it generates an explorable 3D scene (decoded as Gaussian splats) in about one second at under $0.01 of inference, makes animation-ready 3D characters from a single image without separate rigging, and generates full-body motion from text or video. Up to 64 input views as spatial context. Available through Viggle's PINOC app and the Viggle API (100 free credits to start). Comparisons vs Meshy and Tripo are Viggle's own blind tests.
