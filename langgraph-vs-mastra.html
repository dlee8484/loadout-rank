Quick verdict

LangGraph is our provisional #1 agent framework and Mastra #3. The practical split is language: LangGraph's docs are Python-first, Mastra is a TypeScript framework. Both core frameworks are open source and free; the paid items are hosted add-ons (LangSmith for LangChain's ecosystem, Mastra's platform).

Pick LangGraph if…

You write Python agents and want durable, stateful graphs with a large community (43.3k GitHub stars).

Pick Mastra if…

You build in TypeScript and want agents, workflows and evals in one framework (28.8k GitHub stars).
