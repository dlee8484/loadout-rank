## Head-to-head comparisons

- **Claude Code vs Cursor** — Claude Code is our provisional #1 coding agent and Cursor our #2. Choose Claude Code if you want a terminal-first agent that also runs in IDEs, desktop and web and you already pay for Claude. Choose Cursor if you want a full AI-first editor with cloud agents and a free tier to start. <https://dlee8484.github.io/loadout-rank/claude-code-vs-cursor.html>
- **Cursor vs GitHub Copilot** — Cursor ranks higher on our provisional list (#2 vs #4), but the two solve different problems. Choose GitHub Copilot if you want the cheapest paid entry ($10/mo), broad IDE support and enterprise plans on GitHub. Choose Cursor if you want an AI-first editor with cloud agents. <https://dlee8484.github.io/loadout-rank/cursor-vs-github-copilot.html>
- **Claude Code vs OpenAI Codex** — Claude Code is #1 and OpenAI Codex #3 in our provisional ranking. Both are agentic coding tools bundled into chat subscriptions. Choose Codex if you want the lowest entry price ($8/mo Go, $20/mo Plus). Choose Claude Code if you prefer Anthropic's models and a terminal-first workflow. <https://dlee8484.github.io/loadout-rank/claude-code-vs-openai-codex.html>
- **Lovable vs Bolt.new** — Lovable is our provisional #1 vibe-coding tool and Bolt.new #2. Bolt publishes simple monthly prices ($25 Pro) that are easy to compare; Lovable uses a credit system whose paid prices we could not read from its page. Try both free tiers on the same prompt before paying. <https://dlee8484.github.io/loadout-rank/lovable-vs-bolt-new.html>
- **Bolt.new vs v0 by Vercel** — Bolt.new ranks #2 and v0 #3 in our provisional vibe-coding list. v0 is the natural pick for React/Next.js UI that deploys to Vercel; Bolt is a more general app builder. Prices below are list prices from each vendor. <https://dlee8484.github.io/loadout-rank/bolt-new-vs-v0.html>
- **Replit vs Bolt.new** — Bolt.new (#2) outranks Replit (#4) in our provisional list, but they differ: Replit is an all-in-one cloud IDE, agent and hosting platform with a $20/mo Core plan, while Bolt is a lighter prompt-to-app builder with a $25/mo Pro plan and a free tier. Replit's pricing page lists Core, Pro and Enterprise plans. <https://dlee8484.github.io/loadout-rank/replit-vs-bolt-new.html>
- **ChatGPT vs Claude** — ChatGPT is our provisional #1 general assistant and Claude #2. Entry prices are similar ($20/mo for ChatGPT Plus vs $17-20/mo for Claude Pro) and both have free tiers. ChatGPT is broader in consumer features; Claude includes Claude Code on Pro and above. Try both free tiers on your own tasks. <https://dlee8484.github.io/loadout-rank/chatgpt-vs-claude.html>
- **Ollama vs LM Studio** — Ollama is #2 and LM Studio #3 in our provisional local-AI ranking. Both are free for local use. Ollama is the lighter, developer-friendly runtime (183K GitHub stars on its site header); LM Studio is a desktop app, now centered on its Bionic agent. Both also sell optional cloud plans. <https://dlee8484.github.io/loadout-rank/ollama-vs-lm-studio.html>
- **LangGraph vs Mastra** — LangGraph is our provisional #1 agent framework and Mastra #3. The practical split is language: LangGraph's docs are Python-first, Mastra is a TypeScript framework. Both core frameworks are open source and free; the paid items are hosted add-ons (LangSmith for LangChain's ecosystem, Mastra's platform). <https://dlee8484.github.io/loadout-rank/langgraph-vs-mastra.html>
